# 扶養チェッカー 🧾

バイト代を記録して、**扶養を超えていないか**（年収の壁）を確認できるツールです。
掛け持ち・源泉徴収（甲欄／乙欄）・確定申告が必要かどうかもまとめてチェックできます。

- インストール不要。**`index.html` をブラウザで開くだけ**で動きます
- データは自分のブラウザ（localStorage）にだけ保存。サーバーには送りません
- 2025年・2026年・2027年のルールに対応（`js/rules.js`）

**すぐ使う**：https://haruki-416.github.io/fuyou-checker/ （データは各自のブラウザにだけ保存されます）

使い方は [guide.html](guide.html)（1ページのガイド）にもまとめています。

## できること

| 機能 | 内容 |
|---|---|
| 給料の記録 | 明細の総支給額（交通費込み）をそのまま入力。課税分は自動計算、振込額を入れると入力ミスもチェック |
| 給料日 | バイト先ごとに給料日（末日も可）と「土日祝なら前倒し／後ろ倒し」を保存。記録時に支給日を自動入力、記録し忘れの月もお知らせ（祝日・年末年始の銀行休業日も計算） |
| 年収の壁チェック | 住民税／親の扶養控除／19〜22歳の特定親族特別控除／所得税／社会保険の扶養 |
| 年末の見込み | 直近3か月の平均から年末の着地を予測し、「あと月いくらまで働けるか」を表示 |
| 掛け持ち対応 | バイト先ごとの集計、甲欄が2か所になっていないかの警告 |
| 源泉徴収チェック | 甲欄なのに引かれすぎ／乙欄なのに引かれていない、を検出 |
| 確定申告の判定 | 還付申告で戻りそうな額、確定申告が必要なケースを表示 |
| 社会保険 | 扶養（130万／150万）と、勤務先の社保加入条件（週20時間など）をバイト先ごとに判定 |
| バックアップ | JSONの書き出し・読み込み（スマホ⇔PC移行にも）、CSV書き出し |

## 使い方

### 1. 自分のPCで使う

```bash
git clone https://github.com/<あなたのユーザー名>/fuyou-checker.git
cd fuyou-checker
```

あとは `index.html` をダブルクリックしてブラウザで開くだけです。

### 2. スマホでも使いたい（GitHub Pages で公開）

1. GitHub でこのリポジトリを Fork（または自分のリポジトリとして push）
2. **Settings → Pages → Build and deployment** で「Deploy from a branch」「`main` / `(root)`」を選んで保存
3. 数分後に `https://<ユーザー名>.github.io/fuyou-checker/` で開けるようになります

公開されるのはツールだけで、入力したデータは各自のブラウザの中にしか保存されません。

### 3. 入力の流れ

1. **自分の情報**：生年月日、だれの扶養か（親／配偶者）、学生かどうか
2. **バイト先**：掛け持ちなら全部。扶養控除等申告書を出したところは「甲欄」、それ以外は「乙欄」
3. **給料の記録**：給与明細を見ながら入力（**支給日**で年が決まるので注意）

## 2026年の年収の壁（給料だけの場合）

| 年収 | 何が起きる | 影響 |
|---|---|---|
| 119万円超 | 自分に住民税がかかる（自治体で少し違う） | 自分 |
| 136万円超 | 親の扶養控除の対象外（16〜18歳・23歳以上） | 親 |
| 150万円以上 | 19〜22歳：健康保険の扶養から外れる | 自分・親 |
| 130万円以上 | 上記以外：健康保険の扶養から外れる | 自分・家族 |
| 159万円超 | 19〜22歳：親の特定親族特別控除が減り始める | 親 |
| 178万円超 | 自分に所得税がかかる | 自分 |
| 197万円超 | 19〜22歳：親の控除がゼロ | 親 |

- 税金は **1〜12月に支給された額・通勤手当を除く**
- 社会保険は **これから1年の見込み・通勤手当を含む**。2026年4月からは労働契約（労働条件通知書）の賃金で判定するのが原則
- 勤務先の社会保険は、2026年10月から月8.8万円（106万円の壁）の要件がなくなり、**週20時間以上**などで判定

## 暗号化バックアップとサーバー同期

### パスワード付きバックアップ
「自分の情報」→「パスワード付きバックアップ」で、中身が読めない JSON を書き出せます（AES-GCM 256bit / PBKDF2-SHA256 60万回）。パスワードを忘れると復元できません。

### サーバー同期（PHP）
PHP が動くサーバーに置くと、スマホと PC で同じデータを使えます。

- 暗号化はブラウザの中で行います。サーバーに届くのは **同期ID・認証トークン・暗号文だけ** で、パスワード・暗号鍵・給料のデータは届きません（サーバー管理者にも読めません）
- 使い方：1台目で「IDを作る」→ パスワードを決めて「接続する」。2台目では同じ ID とパスワードを入れて「接続する」
- 別の端末が先に更新していたら上書きせずに知らせます（rev による競合チェック）
- 総当たり対策として、同じ IP からの認証失敗は1時間20回までです
- **スマホとつなぐ**：PCで「スマホ用のQRコードを作る」を押し、スマホのカメラで読み取るだけ。IDとパスワードの入力は不要です
  - リンクは **1回だけ・10分間** 有効。使い捨ての鍵はリンクの `#` 以降（ブラウザがサーバーに送らない部分）にだけ入り、サーバーには暗号化した受け渡しデータしか置きません
  - 開いた直後にURLから鍵を消すので、ブラウザの履歴にも残りません

**設置の条件**
- PHP 7.4 以上
- **HTTPS 必須**（ブラウザの暗号化機能が https:// でしか動かないため）
- `data/` フォルダに PHP から書き込めること。Apache なら `data/.htaccess` で外から見えないようにしてあります
- **nginx の場合や、より安全にしたい場合**は、`api/config.sample.php` を `api/config.php` にコピーして、保存先を公開フォルダの外にしてください

```php
define('FUYOU_DATA_DIR', '/home/youruser/fuyou-data');
```

ローカルで試すとき：`php -S localhost:8000` を実行して http://localhost:8000 を開く（localhost は http でも暗号化が使えます）。

## ファイルを更新したのに画面が変わらないとき

ブラウザが古い CSS / JS を覚えている（キャッシュ）のが原因です。

- **Ctrl+Shift+R**（Mac は Cmd+Shift+R）で強制再読み込み。スマホはタブを閉じて開き直す
- 画面の一番下に「バージョン」が出ます。古いファイルが混ざっていると、画面上部に赤い帯で警告が出ます
- 改造して配布するときは、`js/app.js` の `APP_VERSION`、`index.html` の `data-app-version` と `?v=` を**同じ番号に上げて**ください（そうすると利用者のブラウザも新しいファイルを読みにいきます）

## ルールの更新（税制改正があったとき）

金額はすべて [`js/rules.js`](js/rules.js) にまとまっています。新しい年を追加するには、既存の年をコピーして数字を書き換えるだけです。

```js
2028: {
  label: '2028年（令和10年）分',
  status: '予定',
  kyuyoMin: 690000,          // 給与所得控除の最低保障額
  kiso: [[1320000, 620000], ...], // 基礎控除
  fuyouIncome: 620000,       // 扶養親族の所得要件
  ...
}
```

変更したらテストを実行してください。

```bash
npm test   # Node.js 18以上（依存パッケージなし）
```

## ファイル構成

```

css/style.css     見た目（ダークモード対応）
js/rules.js       年度ごとのルール（ここを更新）
js/calc.js        計算ロジック（画面に依存しない）
js/app.js         画面の処理
js/holidays.js    祝日・銀行休業日と給料日の計算
js/crypto.js      暗号化（ブラウザ内）
js/vendor/qrcode.js  QRコード生成（qrcode-generator, MIT License, Kazuhiko Arase）
api/sync.php      暗号文を保管する同期API（PHP）
data/             同期データの保存先（外から見えない設定済み）
test/             計算ロジックのテスト
```

## 注意

- 計算は**概算**です。最終的な判断は、勤務先、扶養者の勤務先（健康保険組合）、税務署、市区町村に確認してください
- 給与以外の収入（業務委託・フリマ・投資など）がある場合は「給与以外の所得」に入力してください。ただし複雑なケースは正確に計算できません
- 健康保険組合によって扶養の基準が独自に決められている場合があります
