1. 何ができるか

給与明細の数字を入れるだけで、扶養から外れそうかどうか、あと月いくらまで働けるか、税金が戻ってくるかを自動で判定します。インストールは不要で、ブラウザだけで動きます。

年収の壁チェック住民税・親の扶養控除・19〜22歳の特例・所得税・社会保険の扶養をまとめて判定
年末の見込み直近3か月の平均から年末の着地を予測。「残り月あたりいくらまで」を表示
掛け持ち対応バイト先ごとに集計。甲欄が2か所になっていたら警告
源泉徴収・確定申告引かれすぎの税金が還付申告でいくら戻るか、確定申告が必要かを判定
給料日の自動入力「毎月25日・土日祝は前倒し」などを保存。祝日・年末年始も計算し、記録し忘れも通知
入力ミス防止明細の総支給額（交通費込み）をそのまま入力。振込額を入れると計算が合うかチェック
業務委託にも対応報酬・経費・源泉徴収（10.21%）を記録。給与と合わせた「合計所得」で壁を判定
扶養控除等申告書づくり質問に答えると記入ナビが出て、国税庁のPDFに書き込んだ記入済みPDFも作れる
暗号化バックアップパスワード付きのJSONで書き出し・読み込み
スマホ・PC同期暗号化してサーバーに保存。QRコードを読むだけでスマホとつながる

2. 2026年の年収の壁（給料だけの場合）

年収こえると何が起きる？影響
119万円超自分に住民税がかかり始める（自治体によって少し低い）自分
130万円以上家族の健康保険の扶養から外れる（下の150万円・180万円に当てはまらない人）自分・家族
136万円超親の扶養控除の対象外になる（16〜18歳・23歳以上）。配偶者は配偶者特別控除に切り替わる親・配偶者
150万円以上19〜22歳（配偶者以外）が健康保険の扶養から外れる自分・家族
159万円超19〜22歳：親の控除（特定親族特別控除）が段階的に減り始める親
169万円超配偶者特別控除が減り始める配偶者
178万円超自分に所得税がかかり始める（超えた分の約5%）自分
197万円超19〜22歳：親の控除がゼロになる親

60歳以上・障害者の健康保険の扶養は180万円未満。2025年分・2027年分のルールも入っていて、画面右上で年を切り替えられます。

税金と社会保険では「数え方」が違う

税金の壁（所得税・住民税・親の控除）社会保険の壁（130万円・150万円）
期間1月1日〜12月31日に支給された分（12月分が1月に振り込まれたら翌年）これから1年間の見込み
交通費含めない含める
判定のもと実際にもらった額2026年4月からは労働契約（労働条件通知書）の賃金が原則。残業代など一時的な増加は含めない

勤務先の社会保険に入る条件

2026年10月から「月8.8万円以上」（いわゆる106万円の壁）の条件はなくなりました。いまは週20時間以上・従業員51人以上の会社・学生でないなどがそろうと、勤務先の社会保険に加入します。掛け持ちの時間は合算しません。加入すると家族の扶養からは外れるので、130万円の壁は関係なくなります。

3. 使い始める3つの方法

いちばん簡単

A. 自分のPCで開く

  • フォルダの index.html をダブルクリック
  • 記録・判定・バックアップはすべて使える
  • サーバー同期とQRは使えない
スマホでも見たい

B. GitHub Pages

  • 無料でURLができる
  • データは端末ごとに別々（同期なし）
  • 端末の移行はバックアップで
同期したい

C. PHPのサーバー

  • レンタルサーバーなど
  • スマホとPCで同じデータを使える
  • HTTPSが必須

A. 自分のPCで開く

git clone https://github.com/<ユーザー名>/fuyou-checker.git
cd fuyou-checker
# index.html をブラウザで開く

zipでもらった場合は、解凍して index.html を開くだけです。

B. GitHub Pages で公開する

  1. GitHub にリポジトリを作って push する（または Fork する）
  2. Settings → Pages で「Deploy from a branch」「main / (root)」を選んで保存
  3. 数分後に https://<ユーザー名>.github.io/fuyou-checker/ で開ける
公開されるのはツールだけです。入力したデータは各自のブラウザの中にしか保存されないので、URLを他の人に教えても自分の記録は見えません。

C. PHPのサーバーに置く（同期を使う）

  1. フォルダごとサーバーにアップロードする（例：public_html/fuyou/）
  2. HTTPS で開けることを確認する（ブラウザの暗号化機能は https:// でしか動きません）
  3. data/ フォルダに PHP から書き込めるようにする（多くのレンタルサーバーはそのままでOK）
  4. より安全にしたい場合、または nginx の場合は、保存先を公開フォルダの外にする： 
    cp api/config.sample.php api/config.php
# api/config.php を編集
define('FUYOU_DATA_DIR', '/home/youruser/fuyou-data');
必要なもの：PHP 7.4 以上 / HTTPS / 書き込みできるフォルダ
ローカルで試す：php -S localhost:8000 を実行して http://localhost:8000 を開く（localhost は http でも暗号化が使えます）

4. 最初の入力（3ステップ）

  1. 自分の情報タブ：生年月日、だれの扶養か（親／配偶者／なし）、学生かどうか、住んでいる地域を入れる。
    扶養の判定は「その年の12月31日時点の年齢」で行います。
  2. バイト先タブ：掛け持ちなら全部登録する。
    • 源泉の区分：扶養控除等申告書を出したところは「甲欄」（1か所だけ）、それ以外は「乙欄」
    • 週の所定労働時間・契約上の月収：労働条件通知書の数字。社会保険の判定に使う
    • 給料日・土日祝のとき：「この設定だと 11/25(水)、12/25(金)…」と今後の支給日が出るので確認
  3. 給料の記録タブ：給与明細を見ながら入力する（次の章）
まず触ってみたいときは、「自分の情報」→「サンプルデータを入れてみる」で、20歳の大学生・掛け持ちの例が入ります。

5. 給料の記録のしかた

入力欄給与明細のどこ？メモ
支給日振込日給料日を登録していれば自動で入る。「‹ 前の月 / 次の月 ›」で切り替え
総支給額（交通費込み）「総支給額」「支給合計」通帳の振込額ではない
うち交通費「通勤手当」「交通費」税金の計算では自動で除く。社会保険の判定には含める
所得税「所得税」「源泉所得税」引かれていなければ0
社会保険料健康保険・厚生年金・雇用保険の合計引かれていなければ0
振込額（任意）通帳に入った額入れると入力ミスをチェック

入力中は「税金の計算に使う額（＝総支給−交通費）」が下に表示されます。総支給と振込額が同じなのに税金が引かれている場合など、手取りを入れてしまったと思われるときは保存前に確認が出ます。

6. 業務委託（フリーランス）の場合

支払明細書や請求書でお金をもらう仕事（ライター、採点、デザイン、配達など）は、雇用ではなく業務委託のことが多く、計算のしかたが変わります。

  1. バイト先タブで「働き方」を業務委託・フリーランスにして登録する。外交員や、特定の相手に継続して役務を提供している人は「家内労働者等に当たる」にチェック
  2. 給料の記録で、その仕事を選ぶと入力欄が切り替わる：報酬額（源泉徴収前）／経費／源泉徴収税額（「10.21%で計算」ボタンあり）
  3. 扶養者の勤務先の健康保険に「経費を差し引いて判定するか」を確認し、自分の情報で設定する
アルバイト（給与）業務委託
所得の計算年収−給与所得控除（2026年は最低74万円）報酬−経費（家内労働者等は経費が少なくても69万円まで。給与があればその分を引いた残り）
年収の壁給与所得と業務委託の所得を合計した所得で判定。業務委託があると、画面の壁は「合計所得◯万円」で表示されます（例：親の扶養は合計所得62万円以下）
源泉徴収甲欄・乙欄原稿料・デザイン料などは10.21%（引かれない仕事もある）
年末調整甲欄のバイト先でしてもらえるない。所得税がかかるなら確定申告が必要。源泉徴収されていれば還付申告で戻ることも
住民税勤務先から市区町村に届く確定申告しない場合は、住民税の申告が必要なことがある
勤務先の社会保険週20時間以上などで加入入れない（雇用ではないため）
家族の健康保険の扶養2026年4月から労働契約の賃金で判定報酬も含めた「これから1年の見込み収入」で判定。経費を引くかは健保による
家内労働者等の特例が使えるかどうかは、仕事の内容によって変わります。不安なときは税務署に確認し、確定申告では「家内労働者等の事業所得等の所得計算の特例の適用を受ける場合の必要経費の額の計算書」を使ってください。

7. 扶養控除等（異動）申告書をつくる

メインのバイト先（甲欄）に出す「給与所得者の扶養控除等（異動）申告書」を、申告書タブで作れます。

  1. 年分を選ぶ（いま出すのは令和9年分。2027年最初の給料日の前日まで）
  2. 出すバイト先・会社名・氏名・住所・世帯主などを入力。生年月日は「自分の情報」から自動で入る
  3. 学生なら「勤労学生」を確認（今年の見込みで、合計所得89万円以下ならおすすめ表示）と学校名・学年
  4. 記入ナビに、欄ごとに「何を書くか／空欄／手書き／勤務先が書く」が出る。手書きする人はこれを見ながら書けばOK
  5. 記入済みPDFが欲しい人は、国税庁の入力用PDFをダウンロードして「国税庁のPDFを選んで書き込む」で選ぶ
  6. 開いて確認 → 印刷 → マイナンバーを手書き → 提出
マイナンバーはこのツールでは保存も書き込みもしません。国税庁のPDFもリポジトリには含めず、選んだPDFはこの端末の中だけで処理します。書き込んだPDFは、元と同じく「印刷とフォーム入力だけ許可」の設定で保存されます。
扶養している家族（配偶者・子など）がいる人、障害者控除を受ける人の欄には対応していません。その部分は国税庁の記載例を見て手書きしてください。前年から内容が変わらない場合は、勤務先の指示で「簡易な申告書」（異動がない旨を書くだけ）にできることもあります。

8. ダッシュボードの見かた

  • 上の4つの数字：今年もらった額／年末の見込み／次の壁まであといくら／引かれた所得税
  • 年収の壁：バーの色つき部分がもらった額、しま模様が年末の見込み。壁ごとに「セーフ／もうすぐ／このままだと超える／超えた」
  • 社会保険：契約上の見込み年収と、最近のペース×12の両方で判定。バイト先ごとの社保加入条件も表示
  • 税金・源泉徴収：今年の所得税の見込み、親が受けられる控除、バイト先ごとの源泉
  • やることリスト：確定申告が必要／還付で戻りそう／甲欄が2か所／記録し忘れ、などを表示
  • 月ごとの給料：バイト先別の積み上げグラフと、社会保険の月の目安ライン

見込みはシフトが決まっていれば「自分の情報」→「年末までの見込みを自分で入力する」で上書きできます。

9. スマホ・PCで同期する

方法C（PHPのサーバー）で使っている場合だけ利用できます。

1台目（PC）

  1. 「自分の情報」→「サーバー同期（暗号化）」で「IDを作る」
  2. 同期パスワード（8文字以上、おすすめは12文字以上）を決めて「接続する」
  3. 「記録を保存するたびに自動でサーバーにも保存する」をオンにしておく

2台目（スマホ）

  1. PCで「スマホ用のQRコードを作る」を押す
  2. スマホのカメラでQRコードを読み取って開く
  3. 「PCとつながりました」と出たら完了。IDとパスワードの入力は不要
QRコード（リンク）は1回だけ・10分間有効です。10分以内なら誰が開いてもつながってしまうので、LINEのグループやSNSには貼らないでください。QRが使えないときは、スマホで同じ同期IDとパスワードを入れて「接続する」でもつながります。

別の端末が先に更新していた場合は、上書きせずに知らせます。「サーバーから読み込む」で向こうのデータを取り込むか、「サーバーに保存」で上書きするかを選んでください。

10. データと暗号化のしくみ

データ置き場所だれが読める？
記録・設定ブラウザの中（localStorage）その端末を使える人
同期データサーバーの data/（暗号文）パスワードを知っている人だけ。サーバー管理者も読めない
暗号化バックアップ書き出したJSONファイルパスワードを知っている人だけ
パスワード・暗号鍵サーバーには送らない—
  • 鍵の作り方：パスワードからハッシュ計算を60万回繰り返して鍵を作る（PBKDF2-SHA256）。総当たりで破られにくくするため、わざと時間のかかる計算にしている
  • 暗号化：AES-GCM 256bit。保存のたびにランダムな値を使い、書き換えられたら検出できる
  • サーバーの認証：暗号鍵とは別の「認証トークン」を作って送る。サーバーはそれをさらにハッシュ化して保存。認証の失敗は同じIPから1時間20回まで
  • スマホ用リンク：使い捨ての鍵はURLの # 以降（ブラウザがサーバーに送らない部分）にだけ入り、開いた直後にURLから消える
  • 暗号化はブラウザ標準の Web Crypto API を使い、外部のサイトには一切つながない（QRコード生成も同梱）
パスワードを忘れると、だれにも復元できません。また「次回からパスワード入力を省略する」をオンにすると、暗号鍵がそのブラウザに保存されます。共用のPCではオフにしてください。

11. 更新・改造するとき

ファイルを更新したのに画面が変わらない

ブラウザが古いファイルを覚えているのが原因です。Ctrl+Shift+R（Mac は Cmd+Shift+R、スマホはタブを閉じて開き直す）で再読み込みしてください。画面の一番下にバージョンが表示され、古いファイルが混ざっていると上部に赤い帯で警告が出ます。

税制改正があったとき

金額はすべて js/rules.js にまとまっています。既存の年をコピーして数字を書き換えるだけで、新しい年に対応できます。変更したら npm test でテストを実行してください（Node.js 18以上、依存パッケージなし）。

改造して配布するとき

js/app.js の APP_VERSION、index.html の data-app-version と ?v= を同じ番号に上げると、利用者のブラウザも新しいファイルを読みにいきます。

12. よくある質問・注意

壁を少しこえたら大損する？

所得税は超えた分の約5%がかかるだけなので、いきなり手取りが大きく減ることはありません。影響が大きいのは社会保険の扶養（130万円・150万円）で、外れると自分で保険料を払うことになり、手取りが年20万円前後減ることもあります。親の控除が減る壁は親の税金が増えるので、家族と相談しましょう。

掛け持ちで気をつけることは？

扶養控除等申告書（甲欄）はメインの1か所だけに出します。年末調整はそのバイト先の分しか計算されないので、乙欄で引かれた税金は翌年1月以降に確定申告（還付申告）で取り戻せます（5年以内）。辞めたバイト先も含めて、源泉徴収票は必ずもらっておきましょう。

データが消えた

ブラウザの履歴・Cookieを消したり、プライベートブラウズで開いたりすると、記録が消えることがあります。ときどき「バックアップを書き出す」をしておくと安心です。同期を使っていれば「サーバーから読み込む」で戻せます。

計算は正確？

給料と業務委託の収入を想定した概算です。青色申告特別控除、医療費控除、年金収入などには対応していません。住民税の基準は自治体ごとに少し違い、健康保険組合が独自の基準を持っている場合もあります。最終的な判断は、勤務先、扶養者の勤務先（健康保険組合）、税務署、市区町村に確認してください。
